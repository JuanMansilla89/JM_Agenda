## Contexto

Presentación completa de ASTAY (servicios + productos) ante Eduardo Sánchez, con el objetivo de que pueda evaluar junto a María Inés si avanzan con una propuesta técnico-económica. Mina Chapi es una operación en inicio/reactivación de producción con necesidades urgentes de reportabilidad y sin sistemas formales implementados aún.

## Temas tratados

### 1. Contexto de Mina Chapi / Quilla Resources

- Operación con producción **Open Pit + Underground** (ambos métodos en simultáneo)
- **Reactivando plan de producción** — inicio de operaciones reciente
- Sistema actual: **solo Excel** ("El Excel es nuestro sistema ahorita")
- Necesidad urgente: reportabilidad con trazabilidad de datos, comparación entre áreas, soporte a decisiones

### 2. Presentación servicios ASTAY

- Diagnóstico ASIS (assessment de procesos, sistemas, datos + roadmap)
- Integración de sistemas (>40 sistemas mineros en experiencia)
- Sistemas de reportabilidad y dashboards operacionales
- Automatizaciones (Power Automate, Power Apps, SharePoint)
- Analítica avanzada / Machine Learning

### 3. Productos ASTAY (DataTwin y MineStock)

- **DataTwin**: solo Open Pit en versión actual — Eduardo lo confirmó como limitante para la parte underground
- **MineStock**: modelamiento de stocks, analítica

### 4. Preguntas clave de Eduardo

- **¿Tienen experiencia en Underground?** → Servicios: sí (si hay dato disponible). DataTwin: solo OP aún
- **¿Modalidad de contrato?** → Dos opciones: proyecto cerrado con bolsa de soporte, o acompañamiento continuo
- **¿Qué licencias se requieren?** → Mínimo: Microsoft (SharePoint + Power Automate por flujo). Power BI Desktop es gratuito. No se requiere licencia de ASTAY para servicios
- **¿Cuánto tiempo para llegar al nivel mostrado?** → Proyectos de 3–6 meses por sprint; estrategia: primero KPIs clave para alta gerencia, luego bajar a gerencias y superintendencias
- **¿Qué tan automático es el proceso?** → Depende del sistema de origen. Con solo Excel: se instrumentan flujos de Power Automate con controles de validación, alertas a llenadores, trazabilidad de quién llenó qué y cuándo

### 5. Sistemas de origen disponibles

- **No tienen sistema de gestión de flota ni ERP** aún
- Plan de minado: posiblemente Deswik (ASTAY no tiene integración directa, pero puede leer archivos de salida / SharePoint)
- MyPlan: sí si trabajan con base de datos
- Fuente principal inicial: SharePoint + Excel estructurado con Power Automate
